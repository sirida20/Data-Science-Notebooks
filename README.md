# Data Science Notebooks

This repository contains my Data Science coursework notebooks developed during my Data Science course.

The notebooks were originally created as part of my Data Science coursework and later organized into this repository.

It includes Python fundamentals, machine learning concepts, case studies, and data analysis projects implemented using Python and Google Colab.

## Topics Covered

- Python Programming
- Data Analysis
- Exploratory Data Analysis (EDA)
- Data Visualization
- Data Preprocessing
- Machine Learning Fundamentals
- Regression Techniques
- Classification Techniques
- Model Training and Evaluation
